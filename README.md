# آهن‌ساز — نسخه‌ی اندروید

اپ اندروید ژورنال بدنسازی. صفحه‌ی HTML برنامه داخل یک WebView قرار گرفته (`app/src/main/assets/index.html`)
و چند امکان بومی اندروید به آن اضافه شده است:

- **زنگ و اعلان پایان استراحت** حتی وقتی برنامه در پس‌زمینه است یا گوشی قفل شده (AlarmManager + اعلان با صدای آلارم)
- **پشتیبان‌گیری** مستقیم در پوشه‌ی Downloads گوشی
- روشن ماندن صفحه هنگام تمرین، انتخاب عکس قهرمان از گالری، ذخیره‌ی داده‌ها روی گوشی

## ساخت APK

1. **Android Studio** (نسخه‌ی جدید، مثلاً Koala یا بالاتر) را نصب کن.
2. `File ▸ Open` و پوشه‌ی `ahansaz-android` را انتخاب کن. صبر کن Gradle Sync تمام شود (اولین بار اینترنت لازم است).
   - اگر Studio پیشنهاد به‌روزرسانی Gradle / Android Gradle Plugin داد، قبولش کن.
3. گوشی را با USB وصل کن (Developer options ▸ USB debugging روشن) و دکمه‌ی ▶ Run را بزن،
   یا از منوی `Build ▸ Build Bundle(s) / APK(s) ▸ Build APK(s)` فایل APK بگیر.
   فایل در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود؛ آن را به گوشی بفرست و نصب کن.
4. بار اول، اجازه‌ی **اعلان‌ها** را بده تا زنگ استراحت در پس‌زمینه کار کند.

## نکته‌ها

- فونت‌های Vazirmatn / Lalezar / Bebas Neue از اینترنت (Google Fonts) لود می‌شوند. بدون اینترنت، فونت پیش‌فرض گوشی استفاده می‌شود.
  برای آفلاین‌شدن کامل، فایل فونت‌ها را در `assets/` بگذار و در CSS با `@font-face` معرفی کن.
- داده‌های تمرین داخل حافظه‌ی WebView همین اپ ذخیره می‌شود. حذف اپ یا پاک‌کردن اطلاعات آن، داده‌ها را پاک می‌کند؛
  گاهی از تب «من» پشتیبان بگیر.
- برای ویرایش برنامه، فقط `app/src/main/assets/index.html` را تغییر بده.
- برای انتشار در گوگل‌پلی باید APK/AAB را با کلید امضای خودت (`Build ▸ Generate Signed Bundle / APK`) بسازی.

## ساخت APK با GitHub (بدون Android Studio)

1. در GitHub یک ریپوی جدید بساز (Private یا Public).
2. همه‌ی فایل‌های این پروژه را در ریپو آپلود کن (پوشه‌ی مخفی `.github` هم باید باشد).
3. به تب **Actions** برو؛ ساخت خودکار شروع می‌شود (حدود ۳ تا ۶ دقیقه). اگر شروع نشد: `Build APK ▸ Run workflow`.
4. بعد از تمام شدن، از بخش **Releases** سمت راست صفحه‌ی ریپو فایل `ahansaz.apk` را دانلود کن
   (یا در صفحه‌ی همان اجرا، از بخش Artifacts).
5. APK را روی گوشی باز کن؛ اگر اندروید پرسید، اجازه‌ی «نصب از این منبع» را بده.
